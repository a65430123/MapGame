# 🌏 地圖探險家 MapGame

以 **Google Maps** 為基底的網頁探索遊戲：你的角色會出現在真實世界地圖上，透過移動與瀏覽地圖探索世界，還能「走進」Google 街景，在街景中看到自己的角色與寶物。

## 玩法

| 功能 | 說明 |
| --- | --- |
| 🧙 角色 | 開始時選擇名稱與角色外觀，角色會站在地圖上，移動時有走路動畫並留下足跡 |
| 🕹️ 地圖移動 | `W A S D` / 方向鍵移動，按住 `Shift` 奔跑；或直接**點擊地圖**讓角色走過去。手機可用螢幕方向鍵 |
| 👁️ 街景模式 | 按 `V` 或「街景」按鈕，從角色所在位置進入街景（也可以拖曳地圖右側的小黃人）。角色以第三人稱顯示在街景畫面中，寶物也會依真實方位與距離出現在街景裡 |
| 🚶 街景移動 | `W`/`↑` 前進、`S`/`↓` 後退、`A`/`D`/`←`/`→` 轉向，`Esc` 回到地圖；街景中的移動會同步角色在地圖上的位置 |
| 💎 寶物 | 角色附近會隨機出現金幣、蘋果、鑽石、王冠等寶物（有稀有度），走近即可收集獲得經驗值；左上角的指示器會告訴你最近寶物的方向與距離 |
| 🗺️ 發現地區 | 移動時會自動辨識所在的城市／行政區，第一次到達的地區與國家會獲得額外經驗值 |
| 🌀 傳送 | 搜尋任何地名、選擇熱門景點、隨機城市或自己的實際位置瞬間傳送 |
| 📖 冒險日誌 | 查看等級、寶物圖鑑、發現過的地區（可點擊傳送回去） |

進度（位置、等級、收藏、發現紀錄）會自動儲存在瀏覽器的 localStorage。

## 開始遊玩

1. 到 [Google Cloud Console](https://console.cloud.google.com/google/maps-apis) 建立 API 金鑰，並啟用：
   - **Maps JavaScript API**（必要）
   - **Geocoding API**（地區發現與地名搜尋用，可選）
   
   建議為金鑰設定「HTTP referrer」限制，只允許你的網域使用。
2. 因為使用 ES modules，需要透過本機伺服器開啟（不能直接雙擊 `index.html`）：

   ```bash
   python3 -m http.server 8000
   ```

   然後打開 <http://localhost:8000>
3. 在開始畫面輸入 API 金鑰即可。金鑰也可以：
   - 寫在 `config.js` 的 `apiKey`
   - 用網址參數：`http://localhost:8000/?key=YOUR_KEY`

也可以直接部署到 GitHub Pages 等任何靜態網站空間。

## 專案結構

```
index.html        頁面與 HUD
config.js         API 金鑰設定（選填）
css/style.css     樣式與動畫
js/main.js        遊戲主程式：載入地圖、角色移動、寶物、地區發現、面板
js/streetview.js  街景模式：進入/離開街景、沿道路移動、把角色與寶物投影到街景畫面
js/geo.js         距離、方位角等地理計算
```

### 技術重點

- 角色與寶物使用自訂的 `google.maps.OverlayView` 繪製成 HTML 元素，可自由加入 CSS 動畫，也不需要 Map ID。
- 街景中的寶物是依據相機位置、視角（heading / pitch）與縮放計算的透視投影，所以轉動視角時寶物會固定在真實世界的位置上。
